# Art references

These sources are tracked for art iteration and excluded from the game's
download and offline cache because they live outside `public/`.

The hero pose and locomotion references, the Cutting figures' sources and the
fire deserter's combat and walk sources went with the four-way and 128 px unit
sheets they fed (ADR 0104 T7); every figure is drawn from its top-down sheet
under `public/art/topdown/`. No reference PNG is a runtime URL.
