# Frozen route-ground structure

`paving.png` and `lawn.png` are exact decoded crops from the current main
versions of Ba Dan's western-approach sample and courtyard plate. Forest and
quarry generators read these tracked snapshots so a village-only repaint cannot
alter already approved route art.

Create them once with `scripts/art/snapshot-route-ground-material.ts`; the
manifest records each source crop and a SHA-256 of its decoded RGBA bytes.
