# Painted expression proof — issue #299

This draft is the first vertical slice: Kaya neutral, angry, worried and warm.
The seven-character issue remains open. Sura, Bo, Mira, Gao, Pella and Dorin are
not generated by this slice. Owner same-person / same-style / different-mood
acceptance is pending; no merge or rollout is claimed.

The built-in OpenAI image tool edited the shipped neutral, once per expression.
It did not use PixelLab, an API key, a paid API fallback or an external asset.
The exact prompts are in `docs/art/prompts/portraits/kaya.<mood>.md` and input /
output hashes in `openai-ledger.json`. `openai/` preserves the full returned PNGs.

## Rebuild

With the project's installed Node/tsx/pngjs and Python/Pillow:

```sh
node art/source/portraits-variants/pack-kaya.mjs
```

Set `PORTRAIT_PYTHON` if Python has a non-default path. The existing portrait
importer normalizes the returned PNGs to 512 pixels. The packer composites the
face region with a four-pixel feather over neutral; it includes the entire brow
so moved brows cannot leave a ghost. All non-face regions retain the neutral.
The final encoder uses neutral's 256-color palette with no dithering, and keeps
the original palette index for every unchanged pixel. This prevents generation
or palette noise in the flame, hand, costume and background.

The initial whole-image palette encoding introduced stippling in the flame and
gold trim and was rejected in independent pixel review. It is not shipped.

The neutral palette conversion is a separate commit; its ledger records all
13 current full-color neutrals (the issue's earlier count was 12). Existing
indexed neutrals are untouched. Original neutral blobs remain in base Git
history and local ignored raw intake. No portrait-family budget is raised.

## Runtime and acceptance

Schema fields are optional. Both dialogue presentations select only registered
expression keys and otherwise retain neutral. Variant images load on first use,
outside the service-worker precache; a cold or failed request displays neutral.
Kaya's existing post-forest and gate-defeat lines carry the three expressions;
story wording, outcomes and speaker availability are unchanged.

`review/kaya-expressions-1x-faces-2x.png` shows neutral and three expressions at
native 512px with matching 2x face crops. `review/metrics.json` records files,
hashes and changed-pixel bounds. Metrics do not replace inspected pixels.
Integrated desktop/iPad views and validation outcomes are recorded in the PR.
