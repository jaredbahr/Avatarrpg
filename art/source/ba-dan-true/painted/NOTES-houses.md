# Ba Dan houses: paint notes (round 4, the shipped houses)

The files are `painted/<id>.png` (they were `painted-v4/<id>-v4.png` when painted; the notes below use the ids as shipped). The attempt sheets were kept under `.review/houses-v4-paint/` and are not tracked.

## Method and selection

Built-in image editing was run four times per complete 1536 x 1024 sheet, always using the corresponding v4 sheet as the immutable edit target. Each attempt sheet is retained under `.review/houses-v4-paint/`. Pieces were cut using the supplied JSON rectangles. A full-resolution Sobel edge map was measured with integer-shift normalized cross-correlation over `-20..20` in both axes (a fixed 3 px sampling lattice was used for tractability), for the whole non-background mask and separately for roof, wall, and olive yard regions. The final selection maximized the four-region correlation with a displacement penalty. The mask then supplied binary alpha; transparent RGB is zero. No outline pass was added.

The 1x guide / painted / 50% overlay strips and 3x crops were visually inspected. Ridges, eaves, doors, windows, steps, fence boundaries, porch supports, and the two-roof chimney junction remain coherent. The image tool did not retain every requested small yard item: the potter's four-pot drying bench is simplified/absent, Gao's separate barrel/crate inventory is incomplete, and the southeast shop yard inventory is reduced. The gates remain real gaps and visible cart wheels retain axle structure. No game or tests were run, per task constraint. Python/PIL could not start because the installed Windows launcher points to an unavailable Store session, so the same Sobel/NCC and PNG operations were implemented through review-local C# and Windows bitmap APIs.
