# WebGL bending cel cache lifetime (#322)

- **Updated:** 2026-10-30 UTC. Renderer fix owner: Codex renderer review; integration owner: main orchestrator.
- **Outcome:** The WebGL all-technique animation run completes without Pixi receiving a destroyed sprite texture. No art or ability timing changed.
- **Acceptance:** `every bending technique renders its animation cels on webgl` and the missing-cel fallback pass with no page or shader errors.
- **Location:** Prepared standalone draft at `/workspace/avatarrpg-322-draft`, branch `codex/322-bending-lifetime-draft`, based on current `main` `bc77ae2e`; no PR or push yet. Original source commit `22091e63` remains preserved in the clean `/workspace/avatarrpg-322` worktree; it was cherry-picked as `b61a6304` here. The combined `b7400642` branch also includes the same #322 source change as `5959622f` plus later #341 renderer work; this draft does not copy those later changes.
- **Cause:** PixiBackend's 128-entry canvas texture cache evicted textures while static elevation-base chunk sprites still used them. The focused failure probe found two visible `elevationBaseLayer` sprites with `texture._source === null`; Pixi's batcher then read `alphaMode` from that null source. Frame views share their base texture's source and also need to remain valid while attached.
- **Change:** In `src/render/backends/pixi.ts`, trim the canvas and frame-view caches after the completed render. Keep texture wrappers and sources referenced by sprites on the stage or in the offstage cast-shadow render group; evict idle entries in LRU order. Retire absent actor and cast sprites at their existing per-frame live-key sweeps so a long route does not pin their old textures; returning actors rebuild and rebind. Hidden static decor and elevation sprites stay protected because they can reappear without rebinding. The cache budgets apply to idle candidates while attached textures remain live. The trim logic is in `src/render/backends/pixiTextureCache.ts` so the regression can exercise real Pixi sprite and texture lifetimes without starting WebGL.
- **Decision:** Restored `src/render/fx/particleLayer.ts` to the baseline after the exact failing all-technique case passed with only the PixiBackend fix. Temporary browser diagnostic code was removed. The earlier particle-cache patch is preserved in `/workspace/avatarrpg-env/322-luna-checkpoint.patch` if separately needed.
- **Verification:** On the original source change, the focused WebGL all-technique case passed (1.1-minute test), and the missing-cel WebGL fallback passed (20.6-second test), using the external `322.playwright.config.ts` and port 4322.
